## 怎么读

- **R**：当前路线；小数是该路线下的具体需求，不要求依次全部实施。
- **P / Phase**：同一套旧建设阶段的两种写法，不是两条路线。“Phrase”不是另一套编号。
- **C0**：采集专项；其中 C0-E–I 分别就是 R5.1–R5.5，不能重复计数。
- **H0–H4**：历史数据统一专项；与 C0-H“断线补洞”不是同一件事。
- 旧报告中的 P1/P2 风险优先级、数据库迁移号、测试样本号不作为路线阶段。
